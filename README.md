# papagno/tap

Homebrew casks for my apps.

```bash
brew install --cask papagno/tap/<name>
```

| Cask | App |
| --- | --- |
| `punchlist` | [Punchlist](https://github.com/papagno/punchlist): your GitHub issues and pull requests as a to-do list beside your code |
| `fuel-gauge` | [Fuel Gauge](https://github.com/papagno/fuel-gauge): Claude, ChatGPT and GitHub Copilot usage limits in the menu bar |
